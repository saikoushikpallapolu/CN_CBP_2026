How It Works

Each network frame contains headers and payload bytes (0–255). We map every byte to a pixel brightness value. When tiled sequentially into a 64×64 grid, benign traffic forms predictable structural lines, whereas flood attacks (DDoS) and C2 beacons (Botnet) create distinct visual entropy patterns.
