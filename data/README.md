# data/

Shared datasets for the pipeline. Large binaries are **not** committed (see root `.gitignore`).

| Subfolder | Contents |
|-----------|----------|
| `raw/` | Original PCAP / capture files |
| `processed/` | 2D grayscale traffic images (and any intermediate artifacts) |

Document dataset source, labels (benign / DDoS / botnet), and license in this folder when samples are added.
