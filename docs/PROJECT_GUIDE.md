# CN_CBP_2026 Project Guide

## 1. Project Overview
The primary goal of this project is to build an intrusion detection classification system using Computer Vision techniques. 
The pipeline is structured as follows:
**PCAP network traffic → raw byte/packet extraction → reshaping into 2D grayscale image → CNN classification.**

The project classifies network traffic into three strict classes:
- benign
- botnet
- ddos

## 2. Current Project Status
- **Phase 1 (Data Processing):** Complete. Pipeline successfully extracts packets from raw PCAPs and converts them to image representations.
- **Phase 2 (ML Experimentation):** Complete/Current. The model architecture has been locked in and evaluated across multiple data representations and splitting strategies.
- **Phase 3/4 (Frontend/Integration):** Currently in progress (e.g., branch `phase-4-nidhish`).
- **Experiment 11 (Cross-Source Evaluation):** NOT complete. Currently blocked awaiting full acquisition of independent Source B PCAP files.
- **Current Verified Real Accuracy:** **74.00%** on the chronological hold-out test set using the 400-byte compact representation.
- **Random Split Note:** A 94.67% accuracy result exists historically (Experiment 9). However, this must be explicitly described as a same-source, overly optimistic result due to intra-PCAP packet correlation (adjacent packets in a single flow distributed across train and test sets). **It is NOT genuine unseen-source generalization.**

## 3. Repository Structure

- `classification/` — Contains related classification/API bridging logic (if active).
- `docs/` — Project documentation (including this guide).

## 6. Dataset Setup
- **Raw Data:** The original `100-MiB` PCAP slices belong in `data/raw/<class>/`.
- **Processed Images:** PNG images generated by the pipeline belong in `data/processed_<variant>/`. (Currently `data/processed_packet_compact/`).
- **Generation Method:** The current dataset was generated using `data_processing/packet_compact_convert.py`.
- **Representation Specifications:**
  - **Image Size:** 20x20 pixels
  - **Packet Representation:** Exactly 1 network packet = 1 image.
  - **Byte Capture:** The first 400 bytes of the raw ethernet frame.
  - **Padding/Truncation:** Packets shorter than 400 bytes are zero-padded (black pixels). Packets longer than 400 bytes are truncated (trailing payload discarded).
  - **Class Ordering:** Generated sequentially from the PCAP stream (chronological).
  
**Data Sources:**
- **Source A:** The existing 100-MiB PCAP slices.
- **Source B:** Future independent PCAPs currently being downloaded for Experiment 11 (e.g., `Tuesday-WorkingHours.pcap`).

## 7. Reproducing the Current 74% Result
To reproduce the validated 74.00% accuracy, you must evaluate the `packet_compact_model.pth` checkpoint against the chronologically split 400-byte dataset.

**Evaluation Script:**
Since training scripts automatically retrain, you can evaluate the model safely using a quick inline script from the root directory:

```powershell
$code = @"
import sys, torch
from torchvision import datasets, transforms
from torch.utils.data import DataLoader, Subset
from sklearn.metrics import accuracy_score, f1_score
from ml.model import TrafficCNN

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
transform = transforms.Compose([
    transforms.Grayscale(num_output_channels=1),
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,))
])
dataset = datasets.ImageFolder('data/processed_packet_compact', transform=transform)
dataset.samples.sort(key=lambda x: x[0])

test_indices = []
class_counts = {c: 0 for c in range(3)}
for idx, (path, class_idx) in enumerate(dataset.samples):
    if class_counts[class_idx] >= 1700: test_indices.append(idx)
    class_counts[class_idx] += 1

test_loader = DataLoader(Subset(dataset, test_indices), batch_size=32, shuffle=False)

model = TrafficCNN(num_classes=3).to(device)
model.load_state_dict(torch.load('ml/checkpoints/packet_compact_model.pth', map_location=device)['model_state_dict'])
model.eval()

y_true, y_pred = [], []
with torch.no_grad():
    for images, labels in test_loader:
        outputs = model(images.to(device))
        y_pred.extend(outputs.argmax(dim=1).cpu().tolist())
        y_true.extend(labels.tolist())

print(f'Accuracy: {accuracy_score(y_true, y_pred)*100:.2f}%')
print(f'Macro F1: {f1_score(y_true, y_pred, average="macro"):.4f}')
"@
$code | python -
```

**Expected Result:**
- Accuracy: 74.00%
- Macro F1: 0.7418

## 12. Known Limitations
- **Data Limits:** Currently, only one independent PCAP slice (Source A) exists per class.
- **Generalization Unproven:** True cross-source validation is NOT yet complete.
- **Random Split Bias:** Using a random train/test split on a single PCAP artificially inflates accuracy (up to 94.67%) due to adjacent packet correlation. This is not genuine accuracy.
- **Git Artifacts:** Generated datasets (`data/processed_*`) and raw PCAP files (`data/raw/**/*.pcap`) are strictly excluded from Git via `.gitignore` to prevent repository bloating. Checkpoints (`.pth`) are tracked.

## 15. Troubleshooting
- **Cannot activate `.venv`:** Run `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` in PowerShell as Administrator.
- **Missing packages (`ModuleNotFoundError`):** Run `pip install torch torchvision scikit-learn pandas scapy`.
- **CUDA Unavailable / Slow Training:** Ensure you have the CUDA toolkit and the specific PyTorch-CUDA wheels installed. (The scripts will fall back to CPU automatically).
- **Checkpoint not found:** Ensure you are running scripts from the repository root `CN_CBP_2026`, not from inside the `ml/` directory.
- **Dataset / PCAP not found:** You must physically place the PCAPs into `data/raw/` or run the extraction scripts locally; images and PCAPs are not in Git.
